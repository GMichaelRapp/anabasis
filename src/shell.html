                                                                                  Quick-start guide

                                                                                  Your privacy

                                                                                  Anabasis has no account, no server and no tracking. Your project lives in two places only: the .json file you save, and a working copy in this browser (IndexedDB) so nothing is lost if the tab closes. Anabasis connects to the internet only when you ask it to: looking up a source by DOI (doi.org, Crossref, DataCite), ISBN (Open Library) or web address (Wikipedia’s citation service), checking sources for retractions (Crossref, which receives only the DOIs), checking links (the Internet Archive), backing up to GitHub, or checking for a newer version; Work offline in Settings turns all of those off. Send feedback includes only what you write plus the version, browser and device. A locked project is encrypted (AES-256-GCM) before it is saved or backed up. Anything a project file contains is cleaned on opening, so a file someone sends you can’t run code or call out to the web. Pictures lose their location and camera details when you add them.

                                                                                  A project holds documents, notes and sources. It autosaves in this browser as you work, but the real copy is the .json file you save. Keep that file somewhere backed up (a synced folder or a private GitHub repo).

It carries through to PDF and Word footnotes and to ePub, HTML, Markdown and Substack notes.

Ellipses (…) and [bracketed changes] count as legitimate edits. Long quotations typed or pasted without a note are listed as unlinked.
                                                                                  • Names & spellings. Keep a list of people, organizations, places and terms with their preferred spelling. Variants (Kiev, Prigozin) are highlighted in the draft and fixable in one click. Anabasis also suggests near-duplicate spellings it finds. People and organizations can also have a pseudonym, with other forms of the name to replace (a surname, a nickname): with Use pseudonyms in exports ticked, every export uses the pseudonym while the project keeps the real name. Record each person’s consent too; anyone named in the draft whose consent is pending, declined or withdrawn is flagged in the Outline.
                                                                                  • Source audit (Sources tab → Tools). Citations and share per source, a warning when one chapter leans on a single source, quoted words per source for permissions, sources missing details, and sources you haven’t used.
                                                                                  • Timeline. Give notes an event date (when it happened), then set the board to Timeline to see them in order. Templates → Chronology turns them into a document.
                                                                                  • Comments. Select text and click 💬. Comments are listed under Outline and travel to Word as real margin comments. They’re left out of PDF, ePub and other exports.
                                                                                  • Revision lens. Highlights long sentences (35+ words), passive voice, hedges and filler, and repeated words, and shows grade level; more checks are under Revising & copyediting. It runs on your device, so nothing is sent anywhere.

                                                                                  • Record. Words added per day, your streak, and each chapter’s status and deadline (also shown in the binder).
                                                                                  • Transcripts. On a source, click Transcript…, paste a transcript, select lines, and make quote or paraphrase notes with the timestamp as the locator.
                                                                                  • Versions. Save a named version, see what changed since (word-level), or restore it. Restoring saves your current text as a version first.

                                                                                  Equations

                                                                                  • Choose Insert → Equation in the toolbar (or press Ctrl+Alt+E, or Alt+= as in Word) and type the equation in TeX, the way LaTeX writes it: x^2, \frac{a}{b}, \sqrt{x}, \sum_{i=1}^n, \alpha. The buttons under the box add common pieces, and the preview shows it as you type, with a note if something isn’t right (a missing brace, a command it doesn’t know).
                                                                                  • In the sentence puts it in the line of text. On its own line sets it apart, centered; numbered ones get (1), (2)… at the right margin, renumbered as you add or remove them. In an empty paragraph the box starts with “on its own line”; in a sentence, “in the sentence”.

Select TeX you’ve typed or pasted (with or without its $…$) and open the box to turn it into an equation; Turn TeX in $…$ and $$…$$ into equations in the command palette does a whole document at once. Import Word brings Word equations back in as TeX, so a document can go to Word and back. LibreOffice opens them too, though it draws a few things (boxes, fancy letters like ℝ) more plainly than Word.

LaTeX gets \( … \), equation for numbered ones and \[ … \] for the rest; Markdown and Pandoc get $…$ and $$…$$. Copy for Substack gives the TeX in dollars, to paste into Substack’s own equation block.

                                                                                  Research: threads, claims, review keys & questions

                                                                                  • Select a passage, then use Mark in the toolbar (or ⌘/Ctrl Alt G, then a letter). Marks can run across paragraphs and around citations, and they can overlap. Click a marked passage to see and change its marks. They’re saved with the draft and left out of every export.
                                                                                  • Threads (T) are named, colored highlights that follow a theme, an argument or a person through the whole piece. Step through a thread with ‹ › in the Research tab, read it straight through on the research desk, or turn it into a working document.
                                                                                  • Claims (C) go into a claims register. Anabasis finds the citations inside a claim or right after it, and warns when a claim has no source, rests only on sources rated D–E or 4–5, or was edited after you marked it supported. Set each claim to not checked, supported, needs a source, contested or cut. The fact-check sheet prints the register as a checklist with full citations and the page of each one, and fills in who checked each supported claim and when (your name comes from Settings). As a document puts the same sheet in the project. The CSV opens in any spreadsheet.
                                                                                  • Review keys (R) mark a passage to come back to, with a reason and a due date. Due keys show in the Research tab and on Project home. Snooze one a week or tick it done on the research desk.
                                                                                  • Questions (Q) link passages to an open research question. Questions are shared with Plan. Record what you’ve found and attach notes on the research desk.
                                                                                  • The Oracle (Research tab, or the The Oracle tab beside the writing) is a conversation partner in the manner of ELIZA, the MIT chatbot of the 1960s. It has no AI and nothing goes online: it turns what you say into questions from a script of keywords and patterns, remembers a few things you said, and answers from your own project. It keeps track of what it just asked, so a plain “yes” or “hmm” gets a sensible reply; it answers when you thank it, ask what it thinks, say you’re tired or stuck, or repeat yourself; and it knows your sources’ authors by name. It copes with word endings, a typo or two and “not”; answers a long message at its most telling sentence; points out notes and sources close to what you’re saying, and paragraphs with no citation yet; and, if you saved your last conversation to the journal, picks up where you left off. Say examine: and a claim to hand it to Socrates. Ask what have I written about…, how many claims need a source?, which sources are rated D or E?, what’s open?, what’s due?, any TKs? or how far am I from my word goal? Say note: …, question: …, hypothesis: …, log: … or next step: … (or save that as a question) and it files it, with Undo. Argue the other side makes it push back on a claim until you say stop. Check in starts the day where you left off: what you logged last time and meant to do first, what’s coming up, editing marks and what’s waiting; the first visit each day does it for you. Wrap up (or done for today) asks what you did, what’s left and the first thing next time, puts them in the journal, and signs off with a maxim from Delphi. What should I work on next? lists the project’s urgencies, most pressing first: overdue chapters, follow-ups, an editor’s queries, review keys, your own next steps. It also answers which chapter is weakest?, any queries from my editor?, what’s out on submission? and what’s coming up?, and hands steelman:, pre-mortem, competing explanations: and define: to Socrates. Its script answers openings and endings, cutting, structure, rejection, feedback, deadlines, procrastination, titles and more. Settings → The Oracle sets its manner, gentle, plain or blunt; or tell it “be gentle” or “be blunt”. Select a passage and choose Mark → Consult the Oracle (O) to have it read back with questions. Conversations are forgotten unless you press Save to journal.
                                                                                  • Socrates (the owl beside + Question, or Mark then S) offers questions to start from when you’re not sure what to ask: three at a time, from 475 in 24 kinds (meaning, evidence, assumptions, alternatives, implications, perspectives, sources, causation, time, numbers, comparison, counterfactuals, intelligence analysis, journalism, the shape of the argument, the reader, your own blind spots, the question itself, being stuck, ethics and harm, method, policy, the scholarly conversation, and scene and character). Select a word, a claim, a name or a number first and the questions are about it, fitted to whether it’s a person, a place or event, a term or a claim; some name your sources’ authors, your chapter or a thread. The kind of writing you’re doing, and the kinds of question you use, lean the choice. Examine a claim walks you through the Socratic method: say what the claim’s key phrase means, meet a passage from your own notes that pushes against it, mend the claim, answer one last question, and save the before and after to the journal. Four more walks sit under the questions: Steelman the other side (state the best opposing case, say what you concede, and answer it), Pre-mortem (imagine the piece failed and work out why, with the warnings your project shows), Competing explanations (weigh each piece of evidence against every explanation, the way intelligence analysts do) and Define your terms (pin a word down, then see how you already use it). Question the draft reads the document, or every chapter, for places worth a question: sweeping words, certainty, claims of cause, unnamed authorities, hedges, round numbers and facts in a paragraph with no citation, each with questions that suit it. Questions you take are remembered with the project, aren’t dealt again, and an old one still open comes back when you open Socrates. Shuffle deals three more, Another like this swaps one, and Use this question makes it an open question linked to the passage, ready to edit. Socrates is a deck of good questions, not AI: nothing leaves your computer.
                                                                                  • The evidence grid lays your claims against the sources they cite, with each source’s rating in the cell, so single-source and weakly sourced claims stand out. Everything about… gathers every paragraph, note, source and marked passage that mentions a name or term, including its other spellings from Names & spellings, and can make a dossier document from the results.
                                                                                  • Untick Show marks in the draft in the Research tab to write without the highlights. Hide one thread with its ● button.
                                                                                  • Marking and unmarking can be undone with ⌘/Ctrl Z (or Undo in the message that appears), as long as you haven’t changed the text since. Deleting a whole thread or question undoes in one step.

                                                                                  Literature grid & codes

                                                                                  • The literature grid (research desk) sets your sources against what you’re reading for: five columns to start (main argument, evidence and method, key findings, limits and gaps, how you’ll use it), which you can rename, reorder, remove or add to, and any of your research questions as a column. Write a line or two in each cell; notes on the source tagged with a column’s name, or linked to its research question, show beneath. Draft a literature review turns it on its side: a new document with a section for each theme or question, every source’s summary as a cited sentence, a prompt to compare them, the sources with notes but no summary, and the sources silent on each theme, between an introduction and a close (the How I’ll use it column feeds the close). It’s also under Templates and Export → Other formats. Grid as a document makes it a table with each source cited; Download CSV for a spreadsheet. Plan → Templates has a Literature review outline.

Select a passage and choose Mark → Code passage… (K), or add codes to a note (useful for transcript excerpts and quotes from PDFs and archive photos). Give each code a definition saying when to use it.
                                                                                  • On the research desk, Codes lists every passage and note under a code, counts each code by document and source, and shows which codes turn up together on a note or in a paragraph. Export the codebook as Markdown, the coded excerpts as CSV, or make a document of codes and excerpts.

                                                                                  Getting-started tips

                                                                                  A new, empty document shows a short card of tips for the kind of writing you’re doing. It goes away when you start typing. Pick another kind from the card, close it for one document, or turn tips off in Settings. All of them are here too:

                                                                                  The research journal

                                                                                  • Open Journal on the research desk, or ＋ Today’s entry in the Research tab. It has four parts: the research design, hypotheses, a dated log and a search log. Above the log, Research process offers a prompt for each stage, from topic and first results through research question, keywords, notes on a source (pick the source and its citation goes in, in the document’s style), working title, thesis, outline and Draft 0, to peer feedback. Each sets the kind of entry and tags it with its stage; a tick marks the stages you’ve written about.
                                                                                  • Research design holds the purpose, your research questions (the same ones as in Plan and the Questions tab), methods, sources and data, scope and limitations, ethics and milestones. Tick a question when it’s answered.
                                                                                  • Hypotheses are claims you could be wrong about. Give each a status (untested, supported, mixed evidence, weakened, refuted), the question it answers, and the claims, notes and sources that support or challenge it. Changing the status asks what changed; the change is dated in the hypothesis’s history and recorded in the log.
                                                                                  • The log is a dated record: what you did, found or decided, dead ends, ideas and new questions, with tags and a link to a claim, note, source or question. ⌘/Ctrl Enter adds the entry. Filter by kind or tag, or search it.
                                                                                  • The search log records where you looked, the terms and filters, and how many results you got and kept, so the research can be repeated. It downloads as CSV.
                                                                                  • Research memo makes a document summing up the design, the hypotheses with their evidence, the searches and the last 30 days of the log, ready to send to a supervisor or editor. Methods appendix makes back matter from the methods, sources, searches, scope and ethics. Both are ordinary documents: make them again to bring them up to date.
                                                                                  • This week shows what moved since Monday: words written, log entries, searches, sources and notes added, claims checked, hypothesis changes and questions answered, plus review keys coming due. Step back to earlier weeks with ‹, and Week summary makes a document to send or keep.
                                                                                  • A Next step log entry is a to-do: tick it when it’s done. Open next steps show in This week, the Research tab and the research memo.
                                                                                  • Start from a method, at the top of the research design, fills empty fields with prompts for archival research, interviews, open-source investigation, document analysis, case studies, data analysis, a literature review or investigative reporting. Replace the [brackets]. Add a second method for mixed methods.
                                                                                  • Everything about… searches the journal too, and deleting a hypothesis, entry or search can be undone.
                                                                                  • The Research guide (in the journal, or How each stage works above the log) explains each stage of a project: what to do, an example, what to watch for, and how to tell when it’s done, with Write about this to start a log entry. Checklists cover verifying sources, quotes and numbers, ethics and consent, data and backups, open-source verification, and the last pass before you submit; ticks are saved with the project. Methods has a short practical guide to each method in Start from a method, and the Glossary defines about sixty research terms.

                                                                                  Co-writing and review

                                                                                  • Export → Send a copy for review or co-writing saves a copy of the whole project as a file, with a note for your collaborator. They open it in Anabasis (the web page or the downloaded file; no account), work as usual, save, and send the file back.
                                                                                  • Export → Take changes back opens their file and compares it with what you sent and what you’ve written since. Their edits come into your draft as suggestions under their name, ready to accept or reject; their margin notes, new notes, sources, images and documents are added. Where you both changed the same paragraph, you see the two side by side and choose: keep yours, take theirs as suggestions, or keep both.
                                                                                  • A safety copy of every changed document is kept in Drafts first. Take changes back again later and only what they changed since comes in. A file that wasn’t sent from this project can still be compared: every difference is shown as their suggestion.

                                                                                  Suggest mode & working with editors

                                                                                  • Turn on Suggest in the toolbar (the pen with a plus) and your edits are marked for review instead of made: new text in green, deleted text struck through in red, each signed with your name (set it in Settings). Deleting text you suggested yourself removes it outright.
                                                                                  • The bar above the page counts the changes; step through them with ‹ ›, or click one to accept or reject it. Accept all and Reject all do the lot, and ⌘/Ctrl+Z undoes any of it.
                                                                                  • Word (.docx) exports keep suggestions as tracked changes and margin notes as Word comments. Import Word brings an editor’s tracked changes back as suggestions and their comments as margin notes on the same words. Other exports show suggestions as accepted.

                                                                                  Listening to the draft

                                                                                  • Listen (the speaker in the document bar) reads from the cursor, highlighting each sentence. Pause, skip a sentence either way, change the speed or the voice in the bar above the page. Typing pauses it. Hearing a draft catches repeated words, missing words and sentences that run on.
                                                                                  • Citations and note numbers are skipped unless you tick Read note numbers and citations. The voices are your system’s own, so nothing leaves the computer (a voice marked “online” is the exception).

                                                                                  • The style menu next to the title has 55 styles grouped by field: Chicago (17th and 18th, notes or author-date, with ibid. or archives cited place first), APA, MLA, MHRA, New Hart’s Rules, SBL, Harvard, APSA, ASA, ISA, OSCOLA and Bluebook, AMA, NLM/Vancouver, CSE, IEEE, Nature, Science, ISO 690 and more.
                                                                                  • Sources → Export… saves your sources as BibTeX, RIS or CSL-JSON for Zotero, EndNote, Mendeley or JabRef, all of them or only those cited in the open document. Each source gets a readable key such as tuchman1962guns.
                                                                                  • Export → Pandoc / Quarto package gives the document as Markdown with citations as [@key, p. 12], its bibliography and the citation style file, ready for pandoc --citeproc. LaTeX package gives a main.tex with BibLaTeX \autocite commands and the .bib file, ready for Overleaf or latexmk -xelatex.
                                                                                  • Follow a Zotero library (Sources → Tools → Zotero library file). Zotero doesn’t let web pages talk to it, so Anabasis follows a file instead: in Zotero, right-click a library or collection, choose Export…, pick Better CSL JSON or Better BibTeX and tick Keep updated (this needs the free Better BibTeX add-on). Then choose that file here. New references are added and changed ones updated, matched by citation key, DOI or title and year; your notes on a source stay. Chrome and Edge re-read the file when you come back to the window; in other browsers choose Update now. Nothing goes online.

                                                                                  • New → Or open a finished example loads a complete thesis chapter, long-form article, white paper, book proposal or investigative piece, with sources, notes, a plan, threads, claims, review keys and questions in place.                                                                                   Checking the draft

                                                                                  Proofread (F7, or the toolbar’s ⋯ menu) catches about 400 common misspellings, mixed-up words where they’re almost always wrong (“would of”, “more then”, “your welcome”, “to loose”, “an affect on”), “a” and “an” by the sound of the next word, doubled words, spacing around punctuation, capitals after a full stop, and brackets or quotation marks left open. Fix one, Fix all spellings, or Ignore a word for the whole project. The browser’s own spell checker still underlines unknown words as you type.

                                                                                  Abstract and keywords (Export menu, or Page setup) builds an abstract a part at a time, shaped for a research article, an essay or chapter, or a report. Suggest from the draft fills empty parts with your own sentences to rewrite; the count shows the word limit; Suggest keywords offers the names and terms this document uses more than the rest of the project. With Include on, they go under the title in every export.

                                                                                  • Close to your notes (Outline tab) finds sentences that repeat seven or more words of a quote note, or nine of a paraphrase or summary note, without quotation marks: copied wording that would read as your own. Add quotation marks quotes it and cites the note’s source; Compare shows the two side by side. Your own idea notes are never flagged, and nothing leaves your computer.
                                                                                  • Corroboration (Outline tab) lists paragraphs that rest on one source, or only on sources rated D–E or 4–5 in the Admiralty scale, and shows which sources carry the most citations. It warns when one source carries more than a third of them.
                                                                                  • House style (Outline tab → Rules…) checks numbers, percent, US or U.S., the serial comma, date order, em dashes, curly quotes, ellipses, double spaces and your preferred spellings (Kyiv, not Kiev). Each rule has a Fix all button. Rules are saved with the project.
                                                                                  • Accessibility (Outline tab) flags figures without alt text, headings that skip a level, tables without a header row, and links that say “here” or show a bare address. Exporting to HTML, ePub or Word reminds you if anything is left.
                                                                                  • Find and replace in all documents (the find bar → All documents…, or the command palette) searches every document and, if you like, your notes. Tick the matches to change. Citations and footnotes are never touched, and each changed document gets a safety copy in Drafts first.

                                                                                  Revising & copyediting

                                                                                  • The revision lens (the Revision lens button on the toolbar) shades what to look at again: long sentences, passive voice, hedges and filler, repeated words, and now clichés, runs of sentences all the same length, pet words this document leans on, -ly adverbs and buried verbs (“the implementation of”). Click a chip to show or hide each kind; the quieter ones start hidden.
                                                                                  • Research desk → Revision shows every chapter at once: words, sentence length and variety, long sentences, passive voice and hedges per thousand words, clichés, adverbs, buried verbs and a grade level. A shaded number is worth a look, not a rule. Choose a row for its revision checklist (the argument is clear on page one, each paragraph does one job, every claim has a source, read it aloud…); ticked items are dated and kept with the project. Open with the lens shows each finding in the text; CSV takes the table to a spreadsheet.
                                                                                  • Editing marks (⌘/Ctrl Alt M, or Mark → Editing mark…) are the copyeditor’s set: query to author (AQ), verify, stet, delete, replace with, transpose, close up, add space, capitalize, lowercase, italic, roman, bold, spell out, new paragraph and run in. Each is signed with your name (Settings) and dated, and listed in the Outline tab. The author clicks a mark to accept it, which makes the change, or reject it; Make every change does all that can be done automatically and leaves queries and checks for you. An answered query is kept as a margin comment. Exports leave the marks out.

                                                                                  Contents, numbering, books & submission packages

                                                                                  • Insert → Lists adds a Contents, a List of figures, a List of tables or a List of equations wherever the cursor is. Each fills itself in as you write, and a click goes to the entry. In exports they become links; PDFs add page numbers and Word gets a real Contents field that fills in when the file opens.
                                                                                  • Page setup → Number paragraphs puts ¶ numbers beside each paragraph, in the page and in every export, for policy papers, legal writing and reviews that cite “¶ 12”. Number lines numbers every line in the page, in PDF and in Word.
                                                                                  • Export → Book for print… makes a print-ready PDF for KDP, IngramSpark or a printer: ten trim sizes (5 × 8 to 8.5 × 11, A5, Demy, Royal), mirrored margins with a gutter, optional bleed, chapters that open on a right-hand page with “Chapter 1” above the title, running heads (the book’s title on the left, the chapter’s on the right), roman page numbers in the front matter and 1 from the first chapter, and no stranded lines. It makes the half title, title page, copyright page (with your ISBN, publisher and edition) and contents with page numbers. Documents marked front or back matter go in their places. The summary estimates the page count and the inside margin KDP asks for at that length.
                                                                                  • Export → Submission package… (or Submissions → Build a package…) builds everything an outlet asks for in one .zip: the piece as Word, anonymized for blind review if you like (your name becomes “[Author]”; comments, suggestions and the title block are left out), a separate title page with your affiliation and the word count without notes and references, and your cover letter, pitch, query, synopsis or proposal, started from a template with the title, word count and outlet filled in. It goes on your Submissions list as planned.

Checkpoints live in this browser; Download keeps one elsewhere.
                                                                                  • Transcripts: in the transcript window, Open file… reads caption files (.srt, .vtt), text, or Word. Caption fragments are joined into sentences with speakers and timestamps, and the search box filters the lines.
                                                                                  • Promo kit (Export menu) drafts a numbered thread for X, Bluesky, Threads, Mastodon or LinkedIn with a counter on every post, a Substack subtitle and search description, and quote cards (square, wide or portrait) as PNG.
                                                                                  • Maps can show oblast and province borders (Ukraine, Russia, Belarus, the Middle East, China, the Koreas, Japan, Taiwan, South Asia, the US and neighbors), rivers and lakes with names, a scale bar, and a locator inset when zoomed in. With provinces on, Shade colors a single province. Charts can mark events and shaded periods, fill areas, or split into small multiples on a shared scale.

                                                                                  Acronyms, estimative language & scripts

                                                                                  • Acronyms (Outline tab) are learned when you spell them out and flagged when undefined, defined late or twice, or used once. One click fixes each. A List of Abbreviations fills in on export.
                                                                                  • Estimative language (Outline tab; on automatically for briefs and white papers) underlines vague words like “may” or “could” and offers terms from the ICD 203 likelihood scale. It also flags mixed wordings of the scale, confidence and likelihood in one sentence, and Key Judgments with no confidence level.
                                                                                  • Script mode (Page setup → “This is a video script”) shows run time at your speaking rate, timecodes beside each paragraph or A/V row, two-column A/V tables, “Copy narration”, and a teleprompter. Space plays and pauses, ⌘/Ctrl+↑↓ changes speed, and Mirror flips the text for a prompter mirror.
                                                                                  • GitHub backup (Export menu) commits the project file to a private repository on demand or whenever you save, and can reopen any earlier backup.
                                                                                  • Picking up on another device: enter the same repository and token there, then choose Open a project… in the GitHub dialog (or From GitHub… on Project home). When a newer backup of the open project turns up, made on another device, a notice offers to open it. Backing up over a newer backup asks first, and automatic backups never do it; nothing is lost either way, since every backup stays in the history.

                                                                                  Drafts

                                                                                  • Drafts are made only when you choose. Click Drafts in the bar above the page (or press ⌘/Ctrl+Alt+D) to save one: a fixed copy of this document as it is now, numbered Draft 1, 2, 3…, with an optional name and a note such as “Sent to editor”.
                                                                                  • Compare side by side: the Drafts view lines up any two drafts, or a draft and your current text, paragraph by paragraph. Rewritten paragraphs show the exact words cut and added; new, cut and moved paragraphs are marked down the left edge. Unchanged stretches fold away. J and K jump between changes. You can also compare against another document, such as an alternate version.
                                                                                  • Bring things back: when the right side is your current text, Use this version, Put it back and Remove it work paragraph by paragraph. Restore brings back a whole draft, and Copy to new doc keeps a draft as its own document. Before Anabasis replaces any text for you, it keeps a safety copy, listed separately from your drafts.
                                                                                  • Download comparison saves the side-by-side view as a page you can send to an editor or print.

                                                                                  Figures, tables & the margin

                                                                                  • Figures: the picture button inserts an image, chart or map; you can also paste a screenshot or drop image files onto the page. Type the caption underneath. Figures number themselves (Figure 1, 2…). Click an image to resize it, add alt text, or replace it. Large images are scaled down to 1800 px, and they travel inside the project file.
                                                                                  • Tables: the grid button inserts one with a caption above. Tab moves between cells and adds a row at the end; the bar above the table adds and removes rows and columns. Word import now keeps images and tables.
                                                                                  • List of figures & tables: add it from Templates (front matter), the ⌘K command search, or the manuscript compile options. It fills in on export, with page numbers in PDF.
                                                                                  • Marginalia: the speech-bubble button in the toolbar (⌘/Ctrl+Alt+A) writes a note in the margin beside the line, anchored to the cursor or to selected text. Esc goes back to the text, and an empty note disappears. On narrow screens notes fold into numbered tabs. Page setup decides what exports do with them: Word comments, a separate Marginalia page at the end (with page numbers in PDF and Word), or leave them out.

                                                                                  Substack, imports, autosave & locking

                                                                                  • Export → Substack post copies the document ready to paste: notes become a numbered Notes section, figures stay images, and tables are drawn as images because Substack has no tables. The .zip package has the post and every image, in case something doesn’t paste.
                                                                                  • Import .md (Notes tab) takes a whole folder, such as Notecards or an Obsidian vault, or a few files. Subfolders can become board piles.
                                                                                  • Autosave to file (Settings, Chrome and Edge): after you save the project once, Anabasis writes to the same .json a few seconds after you stop typing. After a restart the browser may ask for one click (Resume autosave) before it can write again.

There’s no recovery if you forget it. After 15 minutes away it hides itself and asks for the password again (change that, or Lock now, in the lock settings).

Export .ics saves them, with your document and project deadlines, as a file Google Calendar, Apple Calendar and Outlook can import.

New project… starts from a kind (book, article, Substack series, white paper, intelligence brief, video script, literary journalism) with a plan template, citation style and target preset.                                                                                   Planning

                                                                                  • Plan (Docs tab) is an outliner for structure before drafting. Each item has a synopsis, a word target, a status, and linked notes, sources and document. Drag notes from the Notes list onto an item to link them.

                                                                                  • Index cards shows one level as cards with synopses. Drag to reorder, and double-click to go inside. Focus branch narrows the plan to one chapter.

                                                                                  • Build drafts turns the plan into documents with headings, synopsis placeholders (as TK flags) and linked notes. The plan then tracks drafted words against targets.
                                                                                  • Freewrite: a timed sprint (optionally with no deleting) saved as a note and linked to the plan item it was about.
                                                                                  • In the Outline tab, drag ⠿ to move whole sections (or single paragraphs, with paragraphs ticked, which gives a reverse outline). ← and → promote and demote headings. Notes renumber automatically, and Undo move reverses the last change.

                                                                                  Reader: PDFs and ePubs

                                                                                  • ePubs open in the reader like PDFs: Read PDF / ePub in the Sources tab, drop one on the window, or link one to a source. DRM-free books only (Project Gutenberg, Standard Ebooks, and publishers that sell without DRM). Each chapter is a sheet; − + change the size of the type. When the book marks its printed pages, a quote gets the page; otherwise it gets the chapter and paragraph (ch. 3, para. 12), or the section’s title when the chapter has no number. A new source comes from the book’s own title, author, publisher, date and ISBN.
                                                                                  • ☰ opens a panel beside the page: Contents (the PDF’s or book’s own), Pages (thumbnails of a PDF), Highlights, Found (every match for Find) and Reading list.
                                                                                  • Where you left off: a PDF or book reopens at the place you stopped, kept in this browser. Opening a source marked To read moves it to Reading; at the end you’re offered Mark as read. The Reading list tab shows what you’re reading and want to read, with how far you’ve got.
                                                                                  • Aa (View): Paper, Sepia or Night; One page or Two pages side by side for a PDF; Book or Plain type for an ePub.
                                                                                  • Highlights without notes: select a passage and choose a color. Click a highlight to change its color, make it a quote note, put it in the draft or remove it. The Highlights tab lists them in order, by color if you like, to copy, download as Markdown, or turn into quote notes all at once. They’re kept with the source in the project file.
                                                                                  • Insert in draft quotes the selection at the draft’s cursor, with its citation and page, and keeps it as a quote note. A short quotation runs into your sentence; a long one becomes a block quotation.
                                                                                  • Read aloud (the speaker) reads from the top of what you can see, or from the passage you’ve selected, a sentence at a time and on to the next page or chapter. It uses the speed and voice you chose for Listen.
                                                                                  • Find lists every match in Found, with its page or chapter and the words around it. Enter goes to the next, Shift+Enter back, Esc clears.
                                                                                  • Take notes (in the reader’s top bar) sets the writing aside: the PDF on the left, a note pad on the right. Write a note and press Ctrl+Enter; select a passage in the PDF and click Quote note to put it in the pad, then add your comment. Notes go to the PDF’s source, with the page filled in as you scroll. Click a note in the list to edit it, or its page to go there. Back to writing returns.
                                                                                  • Read PDF / ePub (Sources tab), drop a PDF on the window, or click Attach PDF / Read PDF on a source. The reader opens beside your draft, and you can drag its left edge to resize it.
                                                                                  • Select a passage, then click Quote note (saved with the page number) or Paraphrase note (opens so you can rewrite it). If the PDF’s page numbers differ from the printed ones, set the page offset (PDF page 15 = printed 1 → 14). PDFs with built-in page labels are handled automatically.
                                                                                  • Quote and paraphrase notes made in the reader leave a highlight on the PDF, yellow for quotes and blue for paraphrases, with a marker in the margin that opens the note (or finds it in the note pad). The highlights are kept with the notes, so they come back whenever you open the PDF.
                                                                                  • Link the PDF to a source with the menu at the top, or choose New source from this PDF. That uses the PDF’s DOI when it has one, otherwise its title, author and date. Linked PDFs are kept in this browser so they reopen from the source, but they’re never put in your project file.
                                                                                  • Read text (in the reader’s top bar) reads a scanned PDF’s pages on this computer, so they can be searched and quoted. It takes a few seconds a page; you can stop it, copy the text, or quote what it read.

Each comes out of the pad, with Undo. Drag the pad by its title to move it; double-click the title to put it back.

                                                                                  Sources

                                                                                  • Enter details by hand, or quick-add by DOI (via doi.org / Crossref) or ISBN (via Open Library). Lookups need an internet connection. Everything else works offline.
                                                                                  • Type titles the way they should print. CSL styles can’t reliably convert title case to APA’s sentence case.
                                                                                  • Copy citation on a source copies its citation or bibliography entry, with italics, in any style and with a page if you give one: for an email, a message or someone else’s document. To cite in your own draft, use Cite at cursor so the bibliography keeps track.
                                                                                  • Zotero users: export a collection as CSL JSON and import it here, or follow a Better BibTeX auto-export so changes come in by themselves (see Citation styles, Zotero, Pandoc & LaTeX). Sources export back out the same way.
                                                                                  • Précis… (a source’s ⋯ menu) writes a rhetorical précis in Woodworth’s four sentences: who said what, with an exact verb (argues, contends, questions…) and a that clause; how the author develops it; the purpose, with an in order to; and the audience and tone. Fill in the parts and it reads as you go. It is saved as a summary note on the source (tagged précis), so it also goes into the annotated bibliography. Insert puts it in the page with a citation; the command palette’s Précis of every source makes one document of them all, each under its bibliography entry.
                                                                                  • Reading list. Set a source’s Reading to To read, Reading or Read, and tick Read this first for the ones that matter most. Chips at the top of the Sources tab filter the list, and Project home shows what’s waiting.
                                                                                  • Check for retractions (Sources → Tools) asks Crossref, which includes the Retraction Watch database, whether any source with a DOI has been retracted, withdrawn or corrected, or has an expression of concern. Only the DOIs are sent, and only when you choose Check. Retracted sources are marked in the list and on Project home.
                                                                                  • Find duplicates (Sources → Tools) finds the same work added twice, by DOI, ISBN, web address, or title, author and year. Merging keeps the record you choose, fills its empty details from the other, and moves every citation, note, photo and grid cell across.
                                                                                  • Evidence files (at the foot of a source): Fingerprint a file… records a SHA-256 fingerprint of a screenshot, video, download or document, worked out in the browser, with when and where you captured it. The file stays where it is. Check a file against these… tells you later whether a copy is byte for byte the same. PDFs linked to a source are fingerprinted automatically.
                                                                                  • Source type: mark a source primary (made at the time or by those involved: documents, records, interviews, data), secondary (analysis of primary sources) or tertiary (summaries: encyclopedias, textbooks). Its notes take the same type unless you set their own. Filter notes and sources by type with the chips at the top of each list, and turn on Group by source type in Page setup to split the bibliography into primary, secondary and tertiary sources.
