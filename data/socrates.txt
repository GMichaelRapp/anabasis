# Socrates: question stems for researchers working alone.
# "@ id | Group name | suits" starts a group; "suits" lists the selections it fits best
# (term, claim, number, source, person, event, none). Each following line is one stem.
# ___ is a blank: the first is filled with the selection, any second one is left for the writer.
# A stem can end with a tag saying what it suits: {p} only a person or group, {x} anything but a person,
# {c} only a claim. Stems can also name parts of your project, filled in when the project has them:
# {author} (one of your sources' authors, one who writes about the selection if any does), {author2} (another),
# {doc} (the document you are in) and {thread} (a thread the selection belongs to, or any thread).
# A stem whose project part is missing is skipped.
