# The Oracle's script: how it answers when you talk to it.
# It works the way Joseph Weizenbaum's ELIZA did (MIT, 1964-66): no understanding, only keywords and
# sentence patterns. The highest-ranked keyword in what you type picks a group; the first pattern in that
# group that fits picks the replies, used in turn so it doesn't repeat itself.
#
#   %sub word = words        rewritten before matching (contractions and shorthand)
#   %syn name = w1 w2 ...    a set of words, written [name] in keywords and patterns
#   @ key key2 [set] | rank  a group: any of these words calls it; higher ranks win
#   > pattern                * matches any run of words, [set] one word from the set, other words literally
#   - reply                  {1} {2}... are the pieces the pattern matched, turned around (my -> your);
#                            {2.} keeps only the opening noun phrase ("my source says X" -> "your source")
#   ~ memory                 kept when the pattern matches, and raised later when the talk runs dry
# Replies that need a piece the pattern left empty are skipped. "@ none" answers when nothing matches.
